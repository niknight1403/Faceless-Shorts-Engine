# Implementation plan

## Sprint 1 — Foundation
Monorepo, local Postgres/Redis, Prisma domain schema, shared TypeScript contracts, API health, worker health and CI.

## Sprint 2 — Product workflow
Authentication, organizations, tenant isolation, projects, scripts, scenes, assets, approvals and durable jobs.

## Sprint 3 — Media pipeline
LLM/TTS/visual provider interfaces, caption timing, FFmpeg rendering, storage and render validation.

## Sprint 4 — Publishing and monetization
OAuth publishing adapters, Stripe checkout/webhooks, credits, usage limits and agency workspaces.

Every sprint ends with executable tests and evidence. A stub is never reported as complete.
